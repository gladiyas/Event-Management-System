# Event-Management-System
# 📅 Upcoming Events & Gallery Portal
A clean, responsive static website designed to showcase upcoming events, lookbooks, and registration details. The project features a structured layout featuring distinct event spaces, a photo gallery module, a linked fashion boutique store, and integrated organizer contact channels.
## 🚀 Live Demo
> 🔗 [View the Live Project](file:///C:/Users/gladi/Downloads/html-youtube-tutorial-main/html-youtube-tutorial-main/Event%20Management%20HTML%20Project/starter/event.html)
---
## ✨ Features
* **Dark Mode Aesthetics:** Implements a high-contrast dark theme optimized for viewing photography layouts and event flyers.
* **Photo Gallery Module:** Dedicated visual showcase sections optimized for event highlights.
* **Dynamic Linking:** Integrated external e-commerce and retail hooks (e.g., Myntra Fashion Store integration).
* **Responsive Architecture:** Clean layout containment built for modern multi-device screens.
---
## 🛠️ Built With
* **HTML5:** Structural layout and semantics.
* **CSS3:** Modern design styling, typography adjustments, and centered structural alignment blocks.
